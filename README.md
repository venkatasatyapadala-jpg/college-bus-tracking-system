# 🚌 College Bus Tracking System

An IoT and web-based college bus tracking system designed to help students track college buses and get useful bus information.

## 📌 Project Overview

The College Bus Tracking System provides a digital solution for monitoring college buses. It helps students know the bus location and makes transportation management easier.

## ✨ Features

* 🚌 College bus tracking
* 📍 Location monitoring
* 📱 Easy-to-use interface
* 🔔 Bus status updates
* 👨‍🎓 Student-friendly system

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* IoT
* GPS
* Arduino / Microcontroller

## 🎯 Objective

The main objective of this project is to make college transportation more convenient by providing bus location and tracking information digitally.
